# Wild Goose Chase

A side-on sports-day sprint: tap LEFT/RIGHT alternately to run. Play in a mobile browser in landscape.

- Play: served by GitHub Pages from `main`.
- Local: `python3 -m http.server` then open http://localhost:8000 (keys: ←/A, →/D run, Space/↑/W jump, ` for debug).
- Add `?seed=123` to the URL for a fixed seed.

See CLAUDE.md for the design and roadmap.
